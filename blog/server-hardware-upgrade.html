Server Hardware Upgrade & Deployment

11 September 2026 • Project 04 / 07

Pendahuluan

Sebelum masuk ke virtualisasi, ada satu tahap fisik yang perlu dibereskan dulu: menyiapkan perangkat servernya. Saya melakukan persiapan dan peningkatan perangkat server melalui pemasangan SSD, pengecekan kondisi hardware, serta memastikan perangkat siap digunakan untuk proses instalasi sistem dan virtualisasi.

Tujuan

  • Menangani perangkat server dengan prosedur yang aman.
  • Melakukan pemasangan SSD sebagai peningkatan media penyimpanan.
  • Mengecek kondisi dan kompatibilitas hardware.
  • Mempersiapkan perangkat untuk instalasi sistem berikutnya.

Tools / Perangkat

  • Perangkat server, SSD, dan perkakas tangan dasar
  • Menu BIOS/UEFI untuk verifikasi perangkat
  • Checklist pengecekan sederhana

Proses yang Dilakukan

  1. Mencatat kondisi awal perangkat sebelum dibuka.
  2. Membuka dan mengakses bagian dalam perangkat dengan hati-hati.
  3. Mengidentifikasi slot dan konektor storage yang tersedia.
  4. Melakukan pemasangan SSD serta merapikan kabel dan konektornya.
  5. Menyalakan perangkat, memastikan SSD terdeteksi, dan menyiapkan urutan boot untuk instalasi.

Kendala / Hal yang Diperhatikan

Bagian yang paling menyita perhatian justru hal-hal kecil: memastikan konektor terpasang pas, tidak ada baut yang tertinggal, dan urutan boot sudah mengarah ke media instalasi. Saya memfoto kondisi sebelum membongkar supaya ada acuan saat merakit kembali, dan selalu memastikan daya benar-benar mati sebelum menyentuh komponen.

Hasil dan Pemahaman

Perangkat siap dipakai untuk tahap instalasi sistem dan virtualisasi, dengan kondisi hardware yang sudah dicek dan dicatat. Saya memahami bahwa kerapian di level fisik menentukan kelancaran semua pekerjaan software sesudahnya.

Pekerjaan fisik yang rapi menghemat waktu debugging yang panjang.

Hal yang Dipelajari

  • Prosedur aman menangani perangkat server.
  • Cara memastikan storage terdeteksi dan siap pakai.
  • Kebiasaan mendokumentasikan kondisi fisik sebelum instalasi software.

Kesimpulan

Tahap ini memang tidak glamor, tapi justru di sinilah saya belajar menghargai fondasi: server yang sehat secara fisik membuat belajar virtualisasi jauh lebih tenang.
