Webmin Server Administration Lab

5 Oktober 2026 • Project 07 / 07

Pendahuluan

Melakukan praktik administrasi server Debian menggunakan Webmin untuk memahami pengelolaan sistem melalui antarmuka berbasis web. Lab ini saya kerjakan di atas VM Debian yang dibuat pada lab Proxmox sebelumnya.

Tujuan

  • Memahami tugas rutin administrasi server.
  • Mempelajari modul-modul utama Webmin.
  • Melatih monitoring resource dan pengelolaan dasar sistem.

Tools / Perangkat

  • Virtual machine Debian dan Webmin
  • SSH dan terminal sebagai pendamping untuk verifikasi
  • Modul bawaan: dashboard, user, service, dan storage

Proses yang Dilakukan

  1. Menginstal Webmin pada VM Debian dan mengakses dashboardnya.
  2. Mengamankan akses login ke antarmuka Webmin.
  3. Menjelajahi monitoring resource: CPU, memori, dan storage.
  4. Mempraktikkan pengelolaan user, service, dan konfigurasi sistem dasar.
  5. Memverifikasi perubahan penting melalui terminal.

Kendala / Hal yang Diperhatikan

Antarmuka grafis memang memudahkan, tapi saya menyadari kemudahan itu bisa membuat malas memahami perintah di baliknya. Jadi setiap perubahan penting saya cek ulang lewat terminal.

Hasil dan Pemahaman

Saya memahami alur kerja administrasi dasar: pantau resource, kelola user dan service, ubah konfigurasi, lalu verifikasi. Ini latihan pengelolaan harian di lingkungan lab — bukan pengelolaan server operasional.

Panel admin yang baik tidak menggantikan pemahaman CLI — ia mempercepat orang yang sudah memahaminya.

Hal yang Dipelajari

  • Alur kerja admin: monitor, analisis, aksi, verifikasi.
  • Dasar pengamanan akses administratif.
  • Kebiasaan mencatat setiap perubahan konfigurasi.

Kesimpulan

Lab ini menutup rangkaian seri ini dengan rapi: dari merancang jaringan, membangun server, sampai merawatnya agar tetap sehat.
