Proxmox Virtualization Server

17 September 2026 • Project 05 / 07

Pendahuluan

Dengan perangkat server yang sudah siap, saya lanjut ke tahap berikutnya: belajar virtualisasi. Saya melakukan instalasi Proxmox VE dan mempelajari bagaimana satu perangkat server dapat digunakan untuk menjalankan beberapa virtual machine.

Tujuan

  • Memahami konsep dasar virtualisasi server.
  • Mempelajari instalasi dan konfigurasi awal Proxmox VE.
  • Mempraktikkan pembuatan virtual machine Debian.
  • Memahami alokasi resource dan networking VM secara umum.

Tools / Perangkat

  • Proxmox VE
  • ISO installer Debian
  • Web interface Proxmox dan akses SSH

Proses yang Dilakukan

  1. Menginstal Proxmox VE pada server yang sudah disiapkan.
  2. Mengakses web interface dan mengenal menu-menu utamanya.
  3. Menyiapkan storage dan ISO installer Debian.
  4. Membuat virtual machine: mengatur CPU, RAM, disk, dan jaringan secara dasar.
  5. Menginstal Debian di dalam VM dan memastikan VM terhubung ke jaringan.

Kendala / Hal yang Diperhatikan

Alokasi resource ternyata tidak bisa asal besar — permintaan yang berlebihan membuat host terasa berat. Saya mengulang pembagian CPU dan RAM sampai proporsinya masuk akal untuk kebutuhan lab.

Hasil dan Pemahaman

Saya memahami cara kerja virtualisasi dari sisi praktik: instalasi hypervisor, pembuatan VM, sampai VM Debian yang berjalan dan terhubung jaringan. Lab ini murni latihan dasar instalasi dan pembuatan VM, tanpa konfigurasi lanjutan apa pun.

Satu server fisik ternyata bisa menjadi banyak ruang latihan.

Hal yang Dipelajari

  • Perbedaan konsep mesin fisik dan virtual machine.
  • Pengaturan jaringan VM melalui bridge di hypervisor.
  • Disiplin alokasi resource dan kebiasaan snapshot sebelum mengubah sesuatu.

Kesimpulan

Virtualisasi membuka tahap berikutnya dari perjalanan ini: VM Debian yang dibuat di sini menjadi bahan praktik administrasi server di lab selanjutnya.
