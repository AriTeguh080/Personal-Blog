MikroTik Network Configuration Lab

4 September 2026 • Project 03 / 07

Pendahuluan

Dari simulasi, saya lanjut ke perangkat yang sebenarnya — sebagai latihan hands-on. Saya melakukan praktik konfigurasi dasar MikroTik untuk memahami bagaimana sebuah router mengatur jaringan lokal dan mendistribusikan koneksi ke client.

Tujuan

  • Memahami peran router sebagai penghubung sisi WAN dan LAN.
  • Mempelajari konfigurasi IP address, DHCP, NAT, bridge, dan VLAN dasar.
  • Memahami distribusi koneksi internet ke client.
  • Melatih pengecekan konektivitas dan troubleshooting dasar.

Tools / Perangkat

  • Perangkat MikroTik dengan RouterOS, dikonfigurasi lewat WinBox atau terminal
  • Client untuk pengujian konektivitas
  • Perintah ping dan pemantau interface bawaan RouterOS

Proses yang Dilakukan

  1. Memberi alamat IP pada interface sisi WAN dan LAN.
  2. Mengkonfigurasi DHCP server beserta DNS untuk jaringan lokal.
  3. Mengkonfigurasi NAT agar client bisa mengakses internet.
  4. Mengatur bridge dan VLAN dasar untuk kerapian segmen.
  5. Menguji konektivitas dari client sampai ke internet.

Kendala / Hal yang Diperhatikan

Di satu titik, client sudah memperoleh IP tetapi belum bisa membuka internet. Saya memeriksa ulang urutan konfigurasi — IP, DHCP, NAT — dan menemukan bagian yang belum tepat, lalu memperbaikinya.

Hasil dan Pemahaman

Kegiatan ini membantu memahami hubungan antara WAN, LAN, NAT, DHCP, bridge, dan VLAN dalam satu perangkat. Jaringan lab tersambung, dan setiap perubahan saya catat supaya bisa diulang atau dikembalikan.

Konfigurasi yang dicatat sama berharganya dengan konfigurasi yang berhasil — karena lab adalah tempat mengulang.

Hal yang Dipelajari

  • Alur paket di router: dari interface, NAT, sampai firewall dasar.
  • Kebiasaan mencadangkan konfigurasi sebelum mencoba sesuatu yang baru.
  • Membaca status interface dan log sederhana untuk troubleshooting.

Kesimpulan

Lab ini mengubah pemahaman saya dari sekadar tahu konsepnya menjadi pernah menyentuhnya langsung — dan itu terasa bedanya.
