VLAN & Centralized DHCP Simulation

31 Agustus 2026 • Project 02 / 07

Pendahuluan

Setelah membuat rancangan di atas kertas, saya ingin melihat cara kerjanya secara langsung — lewat simulasi. Menggunakan Cisco Packet Tracer, saya melakukan simulasi pembagian jaringan dengan VLAN dan DHCP terpusat untuk memahami bagaimana beberapa kelompok perangkat memperoleh alamat IP sesuai segmentasinya.

Tujuan

  • Memahami segmentasi jaringan menggunakan VLAN.
  • Memahami distribusi alamat IP melalui DHCP terpusat.
  • Memahami fungsi trunk dan access pada perangkat jaringan.
  • Menguji konektivitas antar segmen di lingkungan simulasi.

Tools / Perangkat

  • Cisco Packet Tracer
  • Switch, router, dan PC client di dalam simulasi
  • Konsep VLAN, trunk dan access, DHCP, serta inter-VLAN routing

Proses yang Dilakukan

  1. Membuat beberapa VLAN dan menetapkan port access untuk tiap kelompok perangkat.
  2. Menghubungkan perangkat dengan trunk dan mengatur inter-VLAN routing.
  3. Mengkonfigurasi DHCP terpusat dengan pool alamat untuk tiap segmen.
  4. Menguji setiap client memperoleh IP yang sesuai dan menguji konektivitas antar VLAN.

Kendala / Hal yang Diperhatikan

Di tengah simulasi, ada client yang tidak memperoleh alamat IP. Saya menelusurinya lapis demi lapis — mulai dari status trunk, penugasan VLAN di port access, sampai konfigurasi pool DHCP — sampai ketemu bagian yang terlewat.

Hasil dan Pemahaman

Simulasi membantu memahami alur distribusi DHCP antar VLAN dan fungsi trunk/access pada perangkat jaringan. Setiap kelompok perangkat memperoleh alamat sesuai segmennya, dan saya bisa melihat langsung bagaimana satu server DHCP melayani banyak segmen.

Satu hal yang saya sadari: DHCP terpusat membuat pengelolaan alamat jauh lebih mudah dilacak dibanding setiap segmen mengurus sendiri.

Hal yang Dipelajari

  • Perbedaan port access dan trunk, serta kapan masing-masing dipakai.
  • Cara kerja distribusi DHCP lintas segmen.
  • Kebiasaan troubleshooting berlapis: VLAN dulu, DHCP kemudian, routing terakhir.

Kesimpulan

Sebagai simulasi, lab ini memberi gambaran yang jelas tentang segmentasi — bekal yang nanti kepakai lagi saat membahas firewall dan hardening jaringan.
