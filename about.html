Perjalanan

Perjalanan belajar.

Lima tahap yang saya lalui sejauh ini — ditulis berurutan seperti edisi majalah.

  1. Dasar Networking dan Linux

    Memahami TCP/IP, subnetting, perintah dasar Linux, dan cara kerja layanan jaringan dari sisi client dan server.

  2. VLAN, DHCP, MikroTik, dan Network Infrastructure

    Praktik segmentasi VLAN, DHCP terpusat, routing antar-VLAN, serta konfigurasi MikroTik untuk NAT, bridge, dan distribusi internet.

  3. Server Hardware dan Virtualization

    Upgrade hardware server (SSD), persiapan deployment, lalu virtualisasi dengan Proxmox VE dan VM Linux.

  4. Cyber Security, IOC, dan Threat Intelligence

    Belajar membaca Indicator of Compromise — IP, domain, URL, hash — memakai sumber terbuka seperti CISA dan ThreatFox.

  5. Server Administration dan Monitoring

    Administrasi Linux lewat Webmin: monitoring resource, user, service, storage, dan konfigurasi dasar sistem.
